# نظام الغزالي الحديث

نسخة منظمة من التطبيق تعمل باستخدام React وVite مع واجهة عربية RTL متجاوبة.

الرابط المنشور: https://basmali12.github.io/ghazali-modern-web/

## التشغيل

```powershell
npm install
npm run dev
```

البناء الإنتاجي:

```powershell
npm run build
```

## البنية

- `src/App.jsx`: هيكل React لشاشة الدخول والنوافذ والقائمة الرئيسية.
- `src/styles.css`: التصميم الموحد والمتجاوب.
- `public/legacy.js`: طبقة توافق مؤقتة تحافظ على منطق الفواتير والطباعة وIndexedDB أثناء النقل الآمن.
- `docs/`: البناء الإنتاجي المنشور عبر GitHub Pages.

## توافق البيانات

بقي اسم قاعدة IndexedDB كما هو: `GhazaliSuperDB`. يجب تشغيل النسخة الجديدة على نفس النطاق والمنفذ للوصول مباشرة إلى بيانات المتصفح الموجودة، أو استخدام التصدير والاستيراد عند تغيير عنوان الاستضافة.
